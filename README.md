# ClipNest

ClipNest 是一个本地优先的 AI 剪贴板管家：在任意应用里按下 `Alt+V`，最近复制过的文字、链接、图片、文件和代码片段立刻出现在面板里；需要时再让 AI 帮你解读单条内容、总结一天的复制脉络。

数据默认只保存在本机（SQLite），不登录也能用；登录同步服务后才把历史同步到其他电脑。

## 功能

- **随手唤起**：全局快捷键（默认 `Alt+V`，可改）弹出面板，失焦自动隐藏；上 / 下 / 左 / 右四个方向与自定义边距。
- **自动识别类型**：文字、链接、图片、文件（含资源管理器多选）、代码片段，列表按类型筛选、搜索、收藏。
- **去重与复用**：按内容 SHA-256 去重，重复复制只更新使用次数与时间；删除的内容再次复制会恢复。
- **本地数据库**：sql.js（WASM SQLite）内存运行，写入防抖后以临时文件 + 原子改名落盘；保留策略自动清理，收藏内容永不删除。
- **AI 助手**：任意 OpenAI 兼容接口（DeepSeek / OpenAI / Ollama / Kimi / 智谱 / 通义 / Gemini / 自定义），支持单条解读与标签、每日总结、每日洞察图表。API Key 通过系统 `safeStorage` 加密保存。
- **外观**：深色 / 浅色 / 跟随系统，6 套强调色，支持图片与视频作为面板背景（PNG / JPG / WEBP / GIF / MP4 / WEBM / MOV）。
- **可选同步**：附带零依赖 Node 同步服务，登录后本地优先、按需同步。
- **可迁移存储**：数据库位置可在设置里更改，迁移后自动重启；默认仍是当前配置目录。
- **内网更新分发**：打包后一条命令发布到局域网服务器，客户端自动检查或由服务器推送提醒，下载安装包并校验 SHA-256。
- **局域网共享剪贴板**：同一内网的多台电脑互填 IP 后，一边复制、另一边就能直接粘贴；也可在面板里手动「发给伙伴」。
- **远程启动伙伴程序**：伙伴装了 ClipNest 但已经退出时，点一下「启动」就能通过对方的保活进程把 ClipNest 重新拉起来，不需要 MAC 地址、不受睡眠 / 关机限制。
- **可自定义的设置导航**：侧栏只放固定项，其余收进「更多」；在「更多」页里可以排序、决定哪些固定在左侧（至少保留一个）。
